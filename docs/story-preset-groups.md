# 剧情预设自定义分组

在预设制作器的「专业版」首页输入分组名称，点「新增分组」。新分组可以为空；点进去后用「在本区新增提示词」添加内容。打开已有提示词后，可以用「移动到分组」调整所属分组。

自定义分组支持改名、整组上下移动和取消分组。取消分组保留全部提示词，重新放回未分组区域。内置预设需先点「复制调整」；「角色与世界」等系统连接位保留原有保护规则。

出演模式提示词位于预设的「出演模式」区，支持编辑、启停和排序。`scope` 标记控制它们只在出演模式注入；`{{theater_*}}` 由运行时填入本轮候选角色、交流倾向、近期实际互动、未实现倾向、模式、预设起笔与最近私轴。关闭出演模式时，编译器跳过整个出演区。旧预设导入或打开时会自动补入缺失提示词；未被用户改写的旧默认规则会升级，用户自定义内容保留。

分组边界保存在原生预设的 `prompts[].section` 中（id / name / edge），随保存、复制、备份和 JSON 导入导出保留。边界不发送给模型，提示词仍按数组顺序发送；不带分组信息的旧预设照常显示为「自定义条目」。

剧情重写排除本剧情在角色时间线中的镜像，避免旧版本通过角色近期原文回流。生成成功后在一次事务中原位更新剧场正文，并按新的实际出演名单增删镜像。

代码根据近期实际互动与未实现倾向加权抽取交流关注组，向模型提供全部候选角色资料。模型在同一回复中依次输出正文、实际出演名单 `<turn_cast>`、可省略的事后互动记录 `<interaction_result>` 和私轴 `<private_axes>`。无互动时可以省略记录或写 `[]`，剧情照常生成；不能为填写记录制造互动。独处、沉默或独立行动的角色可列入出演名单。私轴和角色镜像按确认的出演名单保存。名单缺失或无效时，保存已生成的正文。`{{theater_candidate_data}}` 和供旧自定义预设使用的 `{{theater_cast_data}}` 均提供本轮候选名单。

剧场不再提供逐角色原文数量和初始剧情时间设置。角色原文沿用 `loadCharacterContextMessages` 的手动/自适应范围及用户断点，排除本剧情已有独立历史槽位的镜像，保留共同剧情原文去重。旧 `characterContextLimits` 仅保留备份往返，不再影响读取；旧 `characterMemoryDates` 仅作时间线起点兼容，已有镜像的剧情时间优先用于续接。消息仍以实际收发时间记录和排序。旧人数字段不再进入 `StoryCastLimits` 或参与读取、校验与抽取；条目归一化及设置保存只输出 `minGroups/maxGroups`，不批量改写旧数据库。
