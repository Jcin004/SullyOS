# 剧情预设自定义分组

在预设制作器的「专业版」首页输入分组名称，点「新增分组」。新分组可以为空；点进去后用「在本区新增提示词」添加内容。打开已有提示词后，可以用「移动到分组」调整所属分组。

自定义分组支持改名、整组上下移动和取消分组。取消分组保留全部提示词，重新放回未分组区域。内置预设需先点「复制调整」；「角色与世界」等系统连接位保留原有保护规则。

出演模式提示词位于预设的「出演模式」区，支持编辑、启停和排序。`scope` 标记控制它们只在出演模式注入；`{{theater_*}}` 由运行时填入本轮出演名单、交流倾向、近期实际互动、未实现倾向、模式、预设起笔与最近私轴。关闭出演模式时，编译器跳过整个出演区。旧预设导入或打开时会自动补入缺失提示词；未被用户改写的旧默认规则会升级，用户自定义内容保留。

分组边界保存在原生预设的 `prompts[].section` 中（id / name / edge），随保存、复制、备份和 JSON 导入导出保留。边界不发送给模型，提示词仍按数组顺序发送；不带分组信息的旧预设照常显示为「自定义条目」。

剧情重写排除本剧情在角色时间线中的镜像，避免旧版本通过角色近期原文回流。生成成功后在一次事务中原位更新中央正文和镜像；请求失败、并发修改或删除时保留原状态。重写不会额外发起第二次模型请求。

出演模式的动态提示词可使用 `{{theater_cast_data}}`、`{{theater_interaction_tendencies}}`、`{{theater_previous_interactions}}`、`{{theater_unrealized_tendencies}}`、`{{theater_previous_axes}}` 和 `{{theater_prefill}}`。代码先抽取出演名单，再根据近期实际互动与未实现倾向加权抽取交流关注组；剧情结束后读取 `<interaction_result>`，将实际交流与预先倾向分开保存。未发生的交流不会计为完成，也不会额外调用模型。
